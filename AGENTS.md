# Repository Guide

- This is a pnpm 11 (`pnpm@11.22.0`) Turborepo. Run root commands from the repository root; use `pnpm --filter <package> <script>` for focused work.
- The apps are `pathlens-web` (Vite/TanStack Router dashboard), `pathlens-api` (Express/PostgreSQL/Drizzle), `pathlens-tracker` (browser IIFE), `pathlens-heatmap-proxy`, `pathlens-heatmap-proxy-fixtures` (proxy browser fixtures), and `pathlens-snapshot-worker`. `packages/contracts` is browser-safe shared schemas, `packages/backend-types` is server-only, and `packages/ui` owns shared shadcn primitives.
- `pnpm verify` runs the required root sequence: lint, typecheck, then build. Use `pnpm format:check` for a non-mutating formatting check; there is no root test script.
- Focused tests: `pnpm --filter @pathlens/api test:<name>` supports `notifications`, `geoip`, `pagespeed`, `search-console`, `heatmaps`, `preview-sessions`, `authorization`, and `events`; the proxy supports `test`, `test:browser`, `test:browser:js`, and `test:framework`; tracker supports `test:queue` and `test:replay`; snapshot worker uses `test`. Proxy `test:framework` and `preview:manual` build `@pathlens/heatmap-proxy-fixtures` first.
- `.env` and `.env.*` are ignored (only `.env.example` is allowed); inspect each app’s required variables and never commit credentials. Snapshot local execution additionally needs PostgreSQL/AWS values, a private S3 bucket, LocalStack on port `4566`, the `pathlens-snapshot-worker-queue` queue, and Chromium: create the queue with `aws --endpoint-url http://localhost:4566 sqs create-queue --queue-name pathlens-snapshot-worker-queue`, install Chromium with `pnpm --filter @pathlens/snapshot-worker install-browser`, then run `pnpm --filter @pathlens/snapshot-worker local`.
- TanStack Router generates `apps/pathlens-web/src/routeTree.gen.ts`; never edit it. Add web routes under `apps/pathlens-web/src/routes`. Add shared UI components with `pnpm --filter @workspace/ui exec shadcn add <component>` and import them from `@workspace/ui/components/*`.
- For API schema changes, run `pnpm --filter @pathlens/api generate` before `pnpm --filter @pathlens/api migrate`; never hand-edit `apps/pathlens-api/drizzle/meta/**`. Use `pnpm --filter @pathlens/api push` only for deliberate direct database synchronization.
- In `apps/pathlens-api/src/routes/index.ts`, public ingestion/replay/tracking-config, billing, OAuth callbacks, Slack/Google Search Console callbacks, and internal heatmap validation must stay before `ApiKeyMiddleware`. Routes after it require `x-api-key` equal to `INTERNAL_API_SECRET`. Keep `express.raw()` for `/api/billing/webhook` before `express.json()` for Stripe signatures; encrypted tracker requests require `X-Project-Key`, and JWT operations require `JWT_SECRET`.
- Formatting differs by package: root/web use single quotes and no semicolons; API/tracker use double quotes and semicolons; `packages/ui` uses double quotes and no semicolons. Build the tracker with `pnpm --filter @pathlens/tracker build`; its browser artifact is `apps/pathlens-tracker/dist/tracker.global.js`.
