# Repository Guide

- This is a pnpm 11 (`pnpm@11.22.0`) Turborepo. Install and run root commands from the repository root; use `pnpm --filter <package> <script>` for focused work.
- Product code lives in `apps/*`: `pathlens-web` (TanStack Router/Vite dashboard), `pathlens-api` (Express/PostgreSQL/Drizzle), `pathlens-tracker` (browser IIFE), `pathlens-heatmap-proxy`, and `pathlens-snapshot-worker`; `pathlens-heatmap-proxy-fixtures` supplies the proxy’s built browser fixtures. `packages/contracts` is browser-safe, `packages/backend-types` is server-only, and `packages/ui` owns shared shadcn primitives.
- Run `pnpm verify` for the required full check (`lint`, `typecheck`, then `build`); use `pnpm format:check` to check formatting without rewriting. The root has no test script.
- Focused tests: API scripts include `test:notifications`, `test:geoip`, `test:pagespeed`, `test:search-console`, `test:heatmaps`, `test:preview-sessions`, `test:authorization`, and `test:events`; heatmap proxy scripts are `test`, `test:browser`, `test:browser:js`, and `test:framework`; tracker has `test:queue` and `test:replay`; snapshot worker has `test`. Proxy `test:framework`/`preview:manual` build `@pathlens/heatmap-proxy-fixtures` first.
- Copy the relevant app `.env.example` to `.env` and never commit credentials. Snapshot local runs additionally need PostgreSQL/AWS values, a private S3 bucket, LocalStack on port `4566`, the `pathlens-snapshot-worker-queue` queue, and Chromium: create the queue with `aws --endpoint-url http://localhost:4566 sqs create-queue --queue-name pathlens-snapshot-worker-queue`, install Chromium with `pnpm --filter @pathlens/snapshot-worker install-browser`, then run `pnpm --filter @pathlens/snapshot-worker local`.
- TanStack Router generates `apps/pathlens-web/src/routeTree.gen.ts`; never edit it. Add web routes under `apps/pathlens-web/src/routes`. Add shared components with `pnpm --filter @workspace/ui exec shadcn add <component>` and import them from `@workspace/ui/components/*`.
- For API schema changes, run `pnpm --filter @pathlens/api generate` before `pnpm --filter @pathlens/api migrate`; never hand-edit `apps/pathlens-api/drizzle/meta/**`. Use `pnpm --filter @pathlens/api push` only for deliberate direct database synchronization.
- In `apps/pathlens-api/src/routes/index.ts`, ingestion, replay, tracking config, billing, OAuth callbacks, Slack/Google Search Console callbacks, and internal heatmap validation must remain before `ApiKeyMiddleware`; routes after it require `x-api-key` equal to `INTERNAL_API_SECRET`. Preserve `express.raw()` for `/api/billing/webhook` before `express.json()` for Stripe signatures. Encrypted tracker requests require `X-Project-Key`; JWT operations require `JWT_SECRET`.
- Formatting differs by package: root/web use single quotes and no semicolons; API/tracker use double quotes and semicolons; `packages/ui` uses double quotes and no semicolons. Build the tracker with `pnpm --filter @pathlens/tracker build`; its browser artifact is `apps/pathlens-tracker/dist/tracker.global.js`.
