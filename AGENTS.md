# Repository Guide

- This is a pnpm 11 (`pnpm@11.22.0`) Turborepo. Run installs and root scripts from the repository root; use `pnpm --filter <package> <script>` for focused work.
- Pathlens and Airship are separate products. Keep product code in its owning `apps/*` directory. `packages/contracts` is browser-safe, `packages/backend-types` is server-only, and `packages/ui` owns shared shadcn primitives. Before changing Airship web, read `apps/airship-web/AGENTS.md`.
- The main checks are `pnpm lint`, `pnpm typecheck`, `pnpm build`, and `pnpm verify` (`lint`, `typecheck`, then `build`). Formatting is `pnpm format` or `pnpm format:check`; there is no root test script.
- Focused API tests use `pnpm --filter @pathlens/api test:geoip`, `test:pagespeed`, `test:search-console`, `test:heatmaps`, `test:preview-sessions`, or `test:authorization`. Heatmap proxy tests use `pnpm --filter @pathlens/heatmap-proxy test`, `test:browser`, `test:browser:js`, or `test:framework`; `test:framework` first builds `@pathlens/heatmap-proxy-fixtures`. Snapshot tests use `pnpm --filter @pathlens/snapshot-worker test`.
- Copy each app's `.env.example` to `.env`; do not commit credentials. Snapshot capture additionally needs PostgreSQL/AWS values, a private S3 bucket, LocalStack on port `4566` with the `pathlens-snapshot-worker-queue` queue, and Chromium. Create the queue with `aws --endpoint-url http://localhost:4566 sqs create-queue --queue-name pathlens-snapshot-worker-queue`, install Chromium with `pnpm --filter @pathlens/snapshot-worker install-browser`, then run `pnpm --filter @pathlens/snapshot-worker local`.
- TanStack Router generates each web app's `src/routeTree.gen.ts`; never edit it. Add routes under that app's `src/routes`. Add shared UI with `pnpm --filter @workspace/ui exec shadcn add <component>` and import it from `@workspace/ui/components/*`.
- For Pathlens API schema changes, run `pnpm --filter @pathlens/api generate` before `pnpm --filter @pathlens/api migrate`. Never hand-edit `apps/pathlens-api/drizzle/meta/**`; use `pnpm --filter @pathlens/api push` only for deliberate direct database synchronization.
- In `apps/pathlens-api/src/routes/index.ts`, `/events`, `/replay`, tracking config, billing, OAuth/Slack callbacks, Google Search Console callback, and internal heatmap validation must remain before `ApiKeyMiddleware`; routes after it require `x-api-key` matching `INTERNAL_API_SECRET`. Preserve `express.raw()` for the billing webhook before `express.json()` so Stripe signatures work. Encrypted tracker requests require `X-Project-Key`; JWT operations require `JWT_SECRET`.
- The root Prettier config uses single quotes and no semicolons with Tailwind sorting. Preserve local overrides: `apps/pathlens-api` and `apps/pathlens-tracker` use double quotes and semicolons; `apps/airship-web` and `packages/ui` use double quotes and no semicolons. `apps/airship-web` also requires LF endings and 80-column formatting.
- Build the tracker with `pnpm --filter @pathlens/tracker build`; its browser artifact is `apps/pathlens-tracker/dist/tracker.global.js`.
