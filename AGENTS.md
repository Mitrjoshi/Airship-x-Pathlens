# Repository Guide

- This is a pnpm 11 (`pnpm@11.22.0`) Turborepo. Run installs and root scripts from the repository root; use `pnpm --filter <package> <script>` for focused work.
- Product code belongs in its owning `apps/*` package. `packages/contracts` is browser-safe, `packages/backend-types` is server-only, and `packages/ui` owns shared shadcn primitives.
- The required full check is `pnpm verify` (`lint`, then `typecheck`, then `build`). The root has no test script; use package scripts for tests. `pnpm format:check` checks formatting without rewriting files.
- API focused tests are `pnpm --filter @pathlens/api test:notifications`, `test:geoip`, `test:pagespeed`, `test:search-console`, `test:heatmaps`, `test:preview-sessions`, and `test:authorization`. Heatmap proxy tests are `test`, `test:browser`, `test:browser:js`, and `test:framework`; snapshot worker uses `test`. `test:framework` and `preview:manual` first build `@pathlens/heatmap-proxy-fixtures`.
- Copy each needed app `.env.example` to `.env`; never commit credentials. Snapshot local runs require PostgreSQL/AWS values, a private S3 bucket, LocalStack on port `4566`, the `pathlens-snapshot-worker-queue` queue, and Chromium: create the queue with `aws --endpoint-url http://localhost:4566 sqs create-queue --queue-name pathlens-snapshot-worker-queue`, install Chromium with `pnpm --filter @pathlens/snapshot-worker install-browser`, then run `pnpm --filter @pathlens/snapshot-worker local`.
- TanStack Router generates `apps/pathlens-web/src/routeTree.gen.ts`; never edit it. Add routes under `apps/pathlens-web/src/routes`. Add shared UI with `pnpm --filter @workspace/ui exec shadcn add <component>` and import it from `@workspace/ui/components/*`.
- For API schema changes, run `pnpm --filter @pathlens/api generate` before `pnpm --filter @pathlens/api migrate`. Never hand-edit `apps/pathlens-api/drizzle/meta/**`; use `pnpm --filter @pathlens/api push` only for deliberate direct database synchronization.
- In `apps/pathlens-api/src/routes/index.ts`, `/events`, `/replay`, tracking config, billing, OAuth callbacks, Slack/Google Search Console callbacks, and internal heatmap validation must stay before `ApiKeyMiddleware`; routes after it require `x-api-key` matching `INTERNAL_API_SECRET`. Preserve `express.raw()` for `/api/billing/webhook` before `express.json()` so Stripe signatures work. Encrypted tracker requests require `X-Project-Key`; JWT operations require `JWT_SECRET`.
- Formatting differs by package: root and `apps/pathlens-web` use single quotes/no semicolons; `apps/pathlens-api` and `apps/pathlens-tracker` use double quotes/semicolons; `packages/ui` uses double quotes/no semicolons. Build the tracker with `pnpm --filter @pathlens/tracker build`; its browser artifact is `apps/pathlens-tracker/dist/tracker.global.js`.
